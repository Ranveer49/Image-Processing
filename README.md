# Image Processing Projects

A collection of image processing projects developed using Python and OpenCV.

## Projects

### 1. Binary Shape Generator

A Python/OpenCV project for generating binary (black-and-white) images from user-defined text.

The project explores:

* Binary image generation
* Text rendering using OpenCV
* Image dimensions and pixel representation
* Basic image processing operations

**Technologies:** Python, OpenCV, NumPy, Matplotlib
